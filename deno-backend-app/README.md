# Deno Backend App

This application leverages a Taurify backend written using [Deno v2](https://deno.land), which is also Node.js compatible.

The Taurify backend lets you access any Deno API along any [taurify API](https://docs.crabnebula.dev/taurify/api/).

See the [official Taurify backend documentation](https://docs.crabnebula.dev/taurify/backend/) for more information.

## Running

- Install the dependencies:

```
pnpm install
```

- Run the desktop application in development mode:

```
pnpm taurify dev
```
